# Junction 2025 – Fortum Challenge Winning Project

This project was developed during Junction 2025, where our team won the Fortum Challenge. The solution focuses on energy-efficiency insights through a custom web platform that visualizes, filters, and analyzes real-time data. It demonstrates both strong technical execution and practical impact, helping users understand energy consumption patterns and identify optimization opportunities.
